# Accio Work Frontend

基于 Accio Work 产品界面实现的前端项目，包含专家工作台、专家团协作、设计画布、插件管理、定时任务、知识库及 1688 店铺经营等页面。

使用原生 HTML、CSS、JavaScript 构建，无第三方运行依赖。页面采用 Hash 路由，资源使用相对路径，可部署到 GitHub Pages 等静态托管平台。

## 本地运行

需要 Node.js 18 或更高版本。

```bash
npm start
```

打开 `http://localhost:4174`。macOS 也可以双击 `启动项目.command`；保持启动窗口运行即可持续访问。

单专家对话的回答来自知识库后端，需要先启动 `backend/`（默认 `http://127.0.0.1:8000`，可用环境变量 `API_BASE` 修改）。`server.mjs` 把 `/api/*` 转发到后端；后端未启动时，对话中提示「知识库服务未启动」并可重试。

```bash
npm run check
```

## 功能

- 专家首页：切换专家、模型与执行模式、文件附件、插件与技能、工作目录、任务分类。
- 1688 专属首页：店铺关联、客户运营、店铺全景、AI 业务员、五类快捷任务和六种商品图片模板。
- 专家管理：搜索、市场浏览、添加、创建、复制、身份及工具配置。
- 专家团：九套团队模板、自定义成员、任务计划、依赖和交接、任务看板、报告与产物下载。
- 设计画布：图片上传、选择、移动、缩放、图层、文字叠加、颜色预览、撤销与重做。
- 插件与技能：分类、搜索、详情、添加及应用授权表单。
- 定时任务：模板、创建、编辑、调度参数、暂停与删除。
- 知识库：文件夹、上传、搜索、预览、重命名及移除。
- 消息渠道、店铺经营、手机遥控配置、个人设置和帮助页面。

## 实现范围

单专家对话接入知识库后端：从首页或对话框发出的问题经 `/api/chat` 检索作答，回答带来源编号、来源列表和可展开的检索过程；对话顶部可切换提问身份（销售部张三、财务部李四、AI 接待助手），用于对比不同权限下的回答。接入代码在 `dist/live.js` 与 `dist/live.css`，不改动 `app.js`。

专家团协作过程仍由本地状态和预设数据驱动。专家、团队、定时任务与知识库清单保存在浏览器 `localStorage`。图像和视频生成、第三方授权、远程设备控制、消息发送及服务端定时调度未接入后端。

图片上传、文字叠加、颜色滤镜、移动缩放、撤销重做、文件预览与下载使用浏览器能力实现。商品图片素材及补充生成图片的来源见 `1688首页素材说明.md`。

## 项目结构

```text
accio-work-frontend/
├── dist/
│   ├── index.html
│   ├── style.css
│   ├── app.js
│   ├── data.js
│   ├── live.js
│   ├── live.css
│   └── assets/
├── server.mjs
├── package.json
└── 启动项目.command
```

`dist/` 无需构建。只部署静态文件时，界面可正常浏览，单专家对话会提示知识库服务未启动或暂时不可用。上传 GitHub 时请保留 `dist/assets/` 中的图片资源。
