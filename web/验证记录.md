# 前端验证记录

- JavaScript：`npm run check`。
- 差异检查：`git diff --check`。
- 首页：通用专家与 1688 专属界面按当前专家切换，输入框、五个快捷标签、六种图片模板及三个店铺入口可操作。
- 专家团：发送任务后自动推进到任务计划、成员交接、产品设计与最终报告；任务看板与产物查看可用。
- 页面文案：不含讲解入口、播放控制和实现说明；AI 生成内容保留提示标识。
- 单专家对话：首页提问、同一对话追问、切换检索身份，分别返回依据作答、标准问答直答与无依据回复；后端未启动时提示并可重试。
- 设置、授权、画布工具、定时任务、知识库、帮助面板与报告下载内容同步清理。
- 浏览器检查覆盖首页、专家、插件、定时任务、手机遥控、设置、帮助及专家团任务。

后端接入范围见 README。
